# AI Research Copilot - Frontend Application

Modern React 18 + Vite + TypeScript application for evidence intelligence, knowledge discovery, and interactive graph exploration.

## Features
- Interactive Evidence Map & Knowledge Graph using `reactflow`
- TanStack Query server state management with optimistic cache
- Tailwind CSS styling with responsive desktop and mobile drawer navigation
- Multi-step research inquiry wizard with Gemini AI plan preview
- Evidence browser with confidence bars, empirical findings, and excerpts
- Contextual AI Copilot chat with cited source reference chips
- Report preview and markdown download

## Development
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
Default URL: `http://localhost:5173`
